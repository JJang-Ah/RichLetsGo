# 공동 작업 규칙

- 현재 실행 범위는 오프라인 검증이다. 실주문 활성화와 자금 한도는 사용자와 결정한다.
- AI의 의견은 제안이다. 거래소 상태 확인과 위험 제한을 우회하는 주문 권한으로 사용하지 않는다.
- 실거래 수치와 데모 수치를 섞지 않는다. KRW, USD, USDT는 서로 다른 통화로 취급한다.
- 금액과 수량은 Decimal을 사용한다. 주식 수량과 계약 수량 단위를 구분한다.
- 한 작업에서 구현 담당 한 명, 검토 담당 한 명을 정한다. 같은 파일을 동시에 수정하지 않는다.
- 수정 후 의미 있는 테스트를 실행하고 HANDOFF.md에 변경·검증·남은 작업을 기록한다.
- API 키를 출력하거나 문서, 코드, 커밋에 저장하지 않는다.
- 사용자 승인을 재차 요구하는 일반 규칙으로 해석하지 않는다. 승인된 개발 범위 내에서는 진행한다.
