### 테스트 빈틈

- 한도를 넘는 포지션의 전량 청산(발견 1). 결정 후 기대 동작을 테스트로 고정해야 한다.
- 반전 주문(발견 2), 심볼 공백/대소문자(발견 3).
- `Limits` 값 검증이 하나도 테스트되지 않는다: NaN, 0, 음수, float, `max_leverage < 1`.
- `position` 검증: NaN, float, 주식의 음수/소수 포지션.
- 잘못된 `side`(`"Buy"`, `"long"`, `None`)와 문자열로 넘긴 `market`(`"kis_kr"`).
- 국내·미국 주식의 통화 불일치(현재는 선물의 `USD`만 확인), 주식의 `reduce_only=True`.
- `python -m trading_lab` 예제 실행(스모크 테스트).

- `pyproject.toml`이 없어 Python 버전(3.11+)과 향후 의존성이 고정되지 않는다.
- CI(GitHub Actions 등)가 없어 Codex와 Claude가 올린 변경을 자동으로 테스트하지 않는다.
- `.env.example`, 설정 파일 스키마, 키 로딩 방식이 아직 없다.
- 실거래 전 필요한 공통 기반이 없다: 구조화 로그/감사 기록, 주문·체결 저장소(예: SQLite), 시간대 처리(KST, 미국 동부/서머타임, UTC), 스케줄러, 알림, 킬 스위치.
