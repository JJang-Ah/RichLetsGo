## 범위

### 만들 것

1. **4시간봉 만들기** (`strategy/history.py` 등)
   - 마감된 1시간봉 4개(UTC 00·04·08·12·16·20시 시작)를 묶어 4시간봉을 만든다: 시가 = 첫 봉 시가, 고가·저가 = 최대·최소, 종가 = 마지막 봉 종가, 거래량 합.
   - 4개 중 하나라도 없으면 그 4시간봉을 만들지 않는다(D77 데이터 완전성 검사가 이미 1시간봉을 막지만, 함수도 지어내지 않는다).
   - 마감 판정: 4번째 1시간봉이 마감돼야 한다. 미래 정보 차단 테스트를 M2-02와 같은 방식으로.

2. **S2-P 전략** (`strategy/candidates.py`, `models.py`)
   - 매개변수 `S2PParams(rsi_period, lower, atr_period, stop_atr, target_r, max_hold_bars)`. 기본값 없음, 범위 검사(`0 < lower < 50`, `stop_atr > 0`, `target_r > 0`).
   - 입력: 4시간봉 이력, 그 시점 S1 상태, 열린 S2 에피소드(진입가·손절가·진입 봉 포함).
   - 진입 신호(에피소드 없을 때): 01 1.2a절 RSI 되돌림. `MarketSignal(kind=ENTRY, entry_price=종가, stop_price=종가 ∓ k×ATR, limit_price=종가)`.
   - 청산 신호(에피소드 있을 때): 4시간 종가가 목표가(진입가 ± m×(진입가 − 손절가))에 닿음, S1 방향 전환·FLAT, 보유 봉 수 > 최대. 진입가는 **실제 체결가**(에피소드 정보)로 계산한다.
   - 손절가 ≤ 0 이거나 ATR = 0이면 신호 없음(M2-02 규칙과 같음).
   - Wilder 창(10×n), `required_bars` 확장.

3. **지정가 진입과 만료** (실행기·라우터 연결)
   - S2-P 진입은 지정가 주문으로 넣고, **다음 4시간봉 끝**을 유효 기간으로 둔다. M1-05 가상 거래소의 `expires_at`·엄격 돌파·메이커 수수료를 그대로 쓴다.
   - 만료된 진입은 에피소드를 체결 없이 종료한다(M1-04 규칙). 같은 신호로 다시 넣지 않는다.
   - M3-03 어댑터 메모: 실거래는 `timeInForce=PostOnly`. PostOnly 거절은 미체결 포기와 같다(이 작업은 메모만, 구현은 M3-03).

4. **실행기·검증 연결** (M2-03·M2-04)
   - 실행기가 S2-P를 4시간 경계(00·04·…시)에서만 평가한다. 나머지 1시간 경계에서는 체결·손절·펀딩·위험 처리만 한다(D76 순서 그대로).
   - 구간 이동 검증에 조합 `S1B-S2P`, D96 격자 16개, 최소 거래 수 S2 20을 설정으로 넣는다.
   - **선택 규칙 추가**: 정하기 점수 ≤ 0인 후보는 제외한다. 남는 후보가 없으면 `NO_CANDIDATE`(D96). 기존 조합에도 같은 규칙이 적용되도록 설정 항목으로 두되, 첫 캠페인(PR #25) 보고서는 다시 만들지 않는다.

5. **1차 V1 실행 (한 번)**
   - 수집: 2021-03-15부터 두 계약 일봉·1시간봉·펀딩(M2-01). 캠페인 manifest에 D96 전체를 기록한다.
   - 기간 2021-06-01 ~ 2023-09-01, 확인 구간 5개. 보고서를 `docs/reports/`에 남긴다.
   - 보고서 첫머리에 "사전 등록 조건(D96), 결과를 본 뒤 바꾸지 않음"과 manifest 해시를 적는다.
