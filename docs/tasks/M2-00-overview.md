## 목표

Bybit 과거 데이터로 S1·S2 후보 규칙 4개 조합(S1-A/B × S2-A/B)을 구간 이동 검증으로 비교하고, V1 통과 여부를 판정할 수 있는 보고서를 만든다. 실거래·데모와 **같은 전략·위험·체결 코드**를 쓴다(M1-03~05).

어떤 조합도 수익을 보장하지 않는다. M2의 결과물은 "V1 통과 조건(Q21)을 만족하는가"를 판정할 근거다.

## M2 공통 규칙

- **네트워크는 M2-01 수집 명령에서만** 쓴다. 테스트와 CI는 저장된 작은 고정 데이터(fixture)만 쓰고 네트워크에 접근하지 않는다.
- 백테스트 데이터·결과의 위치는 설정의 `paths.backtest.*`에서 받는다(03 3.1절). 코드에 경로를 넣지 않는다.
- 가격·수량·금액은 `Decimal`. 지표 계산 내부는 `float`를 써도 되지만, 주문·손절가·크기 계산으로 넘기기 전에 `Decimal`로 바꾼다(05 5장).
- AI는 `ai.mode=disabled`(D51). AI 효과는 V2에서 본다(P2).
- 위험 수치(Q13)는 아직 미정이다. 백테스트는 설정의 **연구용 위험 프로필**을 쓰고, 보고서 첫머리에 그 값을 표시한다. 이 값은 운용 권고가 아니다.
- 결정성: 같은 데이터·설정·코드면 같은 결과가 나와야 한다. 결과 파일에 데이터 해시, 설정 해시, git 커밋을 남긴다.

- CI(3.12·3.14) 통과. 네트워크 없이 모든 테스트가 돈다.
