## 목표

모든 서비스가 같은 방법으로 설정을 읽고, 비밀 정보는 Windows 자격 증명 관리자에서만 꺼내며, 운영 기록을 파일로 남기게 한다.

## 범위

### 만들 것

1. **설정 로더** (`config/`)
   - 진입점이 받은 설정 파일 경로 하나에서 시작한다. 상대 경로는 설정 파일 부모 폴더 기준(03 3.1절).
   - 불변 dataclass로 읽는다: `environment`, `[bybit]`(계약, 데모/메인 주소), `[bybit_public]`, `[risk]`(Q13 값 — demo는 연구 프로필 D88을 그대로 써도 되고, 값이 없으면 시작 거부), `[ai] mode`(D51), `[paths.<env>]`, `[keystore]` 항목 이름, `[telegram]` 허용 사용자 ID 목록, `[oracle]` 접속 문자열(비밀번호 제외)과 작업 집합 기간 N(M3-02, 데모 주문 보관 7일보다 짧으면 거부), `[strategy.S1]`·`[strategy.S2]`(후보 식별자·모든 필수 매개변수·`source`, M3-04 2번).
   - 검증: 필수 키 누락·형식 오류·환경 간 경로 겹침이면 **시작 거부**(기본값으로 대체하지 않음). 수치는 Decimal 문자열로 받는다.
   - `environment=live`는 M3에서 시작 거부(M3-00 공통 규칙).
   - 읽은 설정의 해시와 비밀 아닌 내용을 `config_versions`(M3-02)에 남길 수 있게 직렬화 함수 제공.
2. **자격 증명 관리자** (`keystore/`)
   - `keyring` 패키지(Windows Credential Manager 백엔드)로 `[keystore]`에 적힌 항목 이름의 값을 읽는다.
   - 값이 없으면 어떤 항목이 없는지만 알려 주고 시작 거부. 값 자체는 로그·예외에 넣지 않는다.
   - API 키는 `ApiCredential(key, secret, created_at)`로 다룬다. `created_at`은 사용자가 설정에 적은 발급일(D75 만료 알림용).
   - 등록 도우미 명령: `python -m richletsgo.keystore set <항목>` — 터미널에서 값을 숨김 입력으로 받아 저장(사용자가 직접 실행).
3. **로그** (`ops/logging` 또는 `config/`)
   - JSON Lines 파일, `paths.<env>.log_dir`에 날짜별 회전, 보관 기간 설정.
   - 모든 레코드에 환경·서비스 이름·시각(UTC)을 넣는다.
   - 비밀 정보 마스킹 필터: API 키·시크릿·토큰·서명 헤더 값을 `***`로 바꾼다.
4. **PR #6 남은 정리**
   - `paths.demo`·`paths.live`의 `backtest_results_dir` 제거(백테스트 전용), 03 6.3절에 Oracle Data Pump `DIRECTORY` 등록 필요 메모(D74), WORKING_RULES 목록 빈 줄 정리.

### 만들지 않을 것

- Oracle 접속 자체(M3-02), 거래소 연결(M3-03)
