# M3-07 데모 1주 운영과 Bybit 실제 동작 확인

- 상태: 명세 작성 완료, 검토 대기
- 실행: 사용자 + Codex(운영 기록) / 확인: Claude Code
- 브랜치: `task/M3-07-demo-run` (운영 기록·발견 사항 문서)
- 근거: 05 3장 M3 완료 조건, 01 1.4절 "M3 데모에서 확인할 것", D41·D42·D58·D62·D79·D88(수수료 재확인), 04 5장(실거래 전 준비 참고)

## 목표

M3-01~06을 데모에서 1주 운영해 M3 완료 조건을 판정하고, **설계가 가정한 Bybit 동작이 실제와 같은지** 확인한다. 다르면 설계 PR을 먼저 낸다.

## 준비 (사용자)

- M2-04 보고서를 보고 데모에 쓸 전략 후보·매개변수를 정해 설정에 넣는다(`source = m2-04:<보고서 해시>`, M3-04 2번).
- Bybit **프로그램 전용 서브 계정** 만들기(D92), 그 서브 계정에서 데모 전환, 데모 API 키 발급(거래 권한만, 출금 권한 없음, IP 제한 없음 D75), 발급일 기록.
- 데모 자금 요청(`demo-apply-money`, 분당 1회).
- 텔레그램 봇 생성, 사용자 ID 확인, 자격 증명 관리자 등록.
- 운영 점검 스크립트(M3-06)로 PC 상태 확인.
