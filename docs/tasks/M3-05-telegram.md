## 목표

텔레그램으로 상태를 알리고, 정해진 명령만 받는다. 이 PC에 들어오는 포트를 열지 않도록 **롱 폴링**(`getUpdates`)을 쓴다.

## 범위

### 만들 것 (`notify/`)

1. **봇 연결**: Bot API HTTPS, 롱 폴링, 토큰은 자격 증명 관리자(M3-01). 받은 업데이트 ID를 저장해 재시작해도 같은 명령을 두 번 처리하지 않는다.
2. **권한**: 모든 명령은 `authorize_command`(M1-03)를 먼저 거친다. 등록되지 않은 사용자는 응답하지 않고 `commands`에 기록.
3. **명령**

   | 명령 | 동작 | 확인 단계 |
   |---|---|---|
   | `/status` | 포지션·손절가, 오늘 손익(D81), 한도 사용률, 정지 상태, 마지막 확정 봉·체결 시각, 키 만료까지 남은 날 | 없음 |
   | `/pause` | `ENTRY_PAUSED_MANUAL` | 없음 |
   | `/resume` | `ResumeService` 요청 → 재확인 메시지(기록용 최고점, 현재 평가액, 낙폭, 다음 정지 수준, 허용 폭) → 확인 버튼. 적용된 실제 값을 응답(D84) | 필수 |
   | `/cancel` | 미체결 **진입** 주문 취소. 손절은 유지 | 필수 |
   | `/resolve <orderLinkId>` | UNKNOWN 주문을 사용자가 Bybit에서 확인한 뒤 `NOT_FOUND` 확정(D54) | 필수 |

   - 확인은 인라인 버튼(콜백)으로 받고, 만료 시간이 있다. 확인 메시지를 보낸 사람만 확인할 수 있다.
4. **알림**: 정지 상태 변화, 체결·손절, UNKNOWN 기한 초과, 장부 불일치, 귀속 보류 기한 초과, 시각 차이 초과, 저널 불확실(D65), 시작·종료, **API 키 만료 14일 전부터 매일**(D75), 매일 UTC 00:00 직후 일일 요약.
   - 같은 알림이 반복되면 묶어서 보낸다(속도 제한 대비). 보내기 실패는 재시도하고 `alerts`에 기록.
   - 알림·응답에 비밀 정보를 넣지 않는다.

### M1-06 수동 대조 인수 (PR #19 P3)

`replacement_exhausted` 그룹은 일반 TRIM(잔량 0 포함)을 계속 인수한다. `/resolve` 계열에서 거래소·전략별 보호를 수동 확인한 뒤 그룹의 exhausted 소유권을 종료하고 새 전체 손절 조회·현재 장부 기반 정리 작업을 생성하는 경로를 구현한다. 단순 정지 해제만으로 과거 작업을 재전송하지 않는다. `history_gap:<symbol>`도 누락 기간을 수동 대조한 뒤 워터마크와 함께 해결해야 한다. `missing_action_order`는 수동 원인 확인·outbox 복원/정리가 필요하며 자동 해제하지 않는다.
