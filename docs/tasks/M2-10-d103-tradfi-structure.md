# M2-10 D103 0단계 2차: TradFi 무기한 시장 구조 수집 계획

- 상태: 계획 초안(2026-11-10, Claude). Codex 검토 → 병합 뒤 수집
- 근거: D103, **04 3.6이 계약 원문**이다. 1차 결과는 `docs/reports/D103-feasibility.md`.
- 담당: 수집 도구와 수집은 Claude가 맡는다(D100: 과거 데이터 수집·도구는 위험이 낮은 작업). 도구 PR은 Codex 검토 뒤 병합한다. 주문·키 경로는 없다.
- 결과물: `docs/reports/D103-structure.md`(2차 보고서). 1차 보고서 6절의 "진행 / 보류" 제안을 갱신한다.

## 목표

TradFi 무기한이 우리 운용 규모에서 거래할 만한지를 **시장 구조 통계로만** 본다. 수익률, 신호, 전략 성과는 계산하지 않는다(04 3.6 3절). 볼 것은 셋이다. (1) 종목별 거래대금, (2) 세션별 스프레드와 호가 깊이, (3) 휴장 뒤 재개 갭 크기.

## 1. 심볼 allowlist (04 3.6 2.3, PR #59 P2-1)

- 출처는 1차 메타데이터 스냅샷(2026-11-10T13:14Z, 응답 sha256은 1차 보고서)이다. 수집 도구는 이 응답을 다시 받아 같은 규칙으로 목록을 만들고, 목록과 그 sha256을 수집 기록에 남긴다.
- 포함 규칙: `symbolType ∈ {stock, ETF, commodity, forex}`, `contractType = LinearPerpetual`, `settleCoin = USDT`, `quoteCoin = USDT`, `status = Trading`, `isPreListing = false`.
- 거절: 알 수 없는 `symbolType`, 스냅샷 이후 분류가 바뀐 심볼(보류), 심볼이나 `baseCoin`이 D98 풀(설계용·판정용) 암호자산과 겹치는 것.
- **모든 요청은 `symbol=`을 명시한다.** symbol을 생략한 `tickers`·`kline`과 WS 전체 구독은 쓰지 않는다. 도구는 요청 URL을 만들 때 allowlist 밖 심볼이면 예외로 멈춘다(테스트로 고정).

## 2. 관측 범위와 남겨 두는 구간 (PR #59 P2-2)

| 구간 | 용도 |
|---|---|
| 과거 1시간봉·펀딩: 각 심볼 상장 시각 ~ **2026-09-01T00:00Z** | 0단계 관측(설계 참고용) |
| **2026-09-01T00:00Z ~ 수집 시작 시각**의 과거 가격 | **받지 않는다.** D104에서 판정 구간 후보로 남겨 둔다 |
| 수집 시작부터 14일간의 실시간 호가 표본 | 0단계 관측(설계 참고용). 이 14일도 판정에 쓰지 않는다 |

- 2026-09-01 이후 상장한 심볼(305개 중 81개)은 과거 봉을 받지 않고, 호가 표본에서만 관측한다.
- 남겨 둔 구간은 6개월 과거의 약 1/3이다. 판정 표본이 작다는 한계는 D104에서 다룬다. 이 경계는 수집 전에 고정하며, 결과를 본 뒤 옮기지 않는다.

## 3. 받을 것

| 데이터 | 엔드포인트(공개) | 범위 | 필드 |
|---|---|---|---|
| 1시간봉 | `GET /v5/market/kline?category=linear&symbol=…&interval=60` | 2절 관측 구간 | start, open, high, low, close, volume, turnover |
| 펀딩 이력 | `GET /v5/market/funding/history?category=linear&symbol=…` | 2절 관측 구간 | 정산 시각, 율 |
| 최우선 호가 | `GET /v5/market/tickers?category=linear&symbol=…` | 14일, **5분마다** 전 심볼(심볼별 요청) | 시각, bid1·ask1 가격·수량, mark, index, last, 24h 거래대금 |
| 호가 깊이 | `GET /v5/market/orderbook?category=linear&symbol=…&limit=50` | 14일, **1시간마다** | 시각, 양쪽 50단계 가격·수량 |

- 요청 속도는 공개 한도보다 충분히 낮게 둔다(초당 5회 이하). 오류나 빈 응답은 재시도 3회 뒤 결측으로 기록한다.
- 저장은 새 SQLite `data/backtest/market_data/d103-tradfi-structure.sqlite`에만 한다. **D98 DB는 열지 않는다.** 수집이 끝나면 data_hash를 계산해 기록한다.
- 분할 등으로 거래가 중단된 구간은 결측으로 두고, 과거 kline이 분할 비율로 조정된다는 점(1차 2절)을 기록한다.
- WS, 키가 필요한 API, 주문 API는 쓰지 않는다.

## 4. 세션 라벨

- 각 시각에 그 심볼의 기초 시장 세션을 붙인다: 정규장, 프리·애프터, 야간, 휴장(주말·공휴일), 조기 종료.
- US는 NYSE 달력(서머타임 포함), KR은 KRX(09:00~15:30 KST), HK는 HKEX(점심 휴장 포함), CN은 해당 거래소 달력을 쓴다. 원자재·외환은 각 기준 시장의 세션(CME 등, 주말 휴장)을 쓴다.
- 달력 출처와 버전을 기록한다. 라벨이 애매한 시각(달력이 없는 공휴일 등)은 "불명"으로 둔다.

## 5. 볼 통계 (수익률 아님)

| 통계 | 정의 |
|---|---|
| 거래대금 | 심볼별 일평균 거래대금(관측 구간), 30일 평균 분포, D99 등급(5M·20M·50M·200M) 구간별 심볼 수. 거래 0인 1시간봉 비율 |
| 스프레드 | `(ask1 − bid1) / mid`를 세션별 중앙값·90분위로. 빈 호가·한쪽 호가 비율 |
| 깊이 비용 | 고정 명목 **1,000 / 5,000 / 20,000 USDT** 시장가를 호가에 대어 본 평균 체결가와 mid의 차이(세션별). 깊이가 모자라면 "미체결"로 센다 |
| 재개 갭 | 휴장 직전 마지막 1시간봉 종가 대비 정규장 재개 첫 1시간봉 시가의 **절대값** 분포(심볼·세션 경계별 중앙값·95분위·최대) |
| 지수·mark 정지 | 호가 표본에서 휴장 중 index·mark가 바뀌지 않은 연속 시간 |
| 펀딩 | 율의 분포(절대값 중앙값·95분위), 상한 도달 비율 |

- 방향이 있는 수익률(롱·숏 손익), 신호, 종목 순위 성과는 계산하지 않는다. 갭은 절대값만 본다.
- RPI 등 API에 보이지 않는 호가는 반영되지 않는다는 한계를 적는다.

## 6. 보고서가 답할 질문

1. D99 등급(20M 이상)을 만족하는 심볼이 몇 개이고, 그중 한국·미국 대형주와 원자재·외환은 무엇인가.
2. 휴장·주말 스프레드와 깊이 비용이 정규장 대비 몇 배인가. 우리 규모(명목 1천~2만 USDT)에서 D99 슬리피지 가정이 맞는가.
3. 재개 갭의 95분위가 일반적인 손절 거리와 비교해 얼마나 큰가(1차 보고서의 "휴장 중 보호 미확인"을 수치로).
4. 이 결과로 1차 제안("보류에 가까운 조건부 진행")을 유지·상향·하향할지.
