# M2-10 D103 0단계 2차: TradFi 무기한 시장 구조 수집 계획

- 상태: 계획 확정(PR #60 eda9672). **M2-10a 수집 도구 구현**(Claude) → Codex 검토·병합 뒤 수집
- 근거: D103, **04 3.6이 계약 원문**이다. 1차 결과는 `docs/reports/D103-feasibility.md`.
- 담당: 수집 도구와 수집은 Claude가 맡는다(D100: 과거 데이터 수집·도구는 위험이 낮은 작업). 도구 PR은 Codex 검토 뒤 병합한다. 주문·키 경로는 없다.
- 결과물: `docs/reports/D103-structure.md`(2차 보고서). 1차 보고서 6절의 "진행 / 보류" 제안을 갱신한다.

## 목표

TradFi 무기한이 우리 운용 규모에서 거래할 만한지를 **시장 구조·위험 통계로만** 본다. 볼 것은 넷이다.
1. 종목별 거래대금
2. 세션별 스프레드와 호가 깊이 비용
3. 세션 재개 전후 가격 변화의 절대 크기(근사)
4. 휴장 중 index·mark 가격이 같은 값으로 머문 시간

방향·보유·신호에 따른 손익, 종목 순위 성과는 계산하지 않는다(04 3.6 3절). 갭 분포로 손절 거리나 보유 시간을 고르지 않는다. 그런 비교는 D104에서 사전 고정한 기준으로만 한다.

## 1. 심볼 allowlist (PR #59 P2-1, PR #60 P2-3)

- **입력은 보존한 1차 메타데이터 원문이다**: `docs/reports/D103-instruments-2026-11-10/`(4개 응답, `SHA256SUMS`). 도구는 시작할 때 해시를 확인하고 이 파일로 목록을 만든다. 새 `instruments-info` 조회는 **변경 감지용**으로만 쓴다.
- 포함 규칙: `symbolType ∈ {stock, ETF, commodity, forex}`, `contractType = LinearPerpetual`, `settleCoin = USDT`, `quoteCoin = USDT`, `status = Trading`, `isPreListing = false`.
- 거절과 보류
  - 알 수 없는 `symbolType`이면 도구가 멈춘다.
  - 수집 직전에 새로 조회한 메타데이터와 비교해, 원문 이후 분류·상태·`symbolId`가 바뀐 심볼은 보류한다. 원문에 없던 새 심볼은 넣지 않는다.
  - 심볼이나 `baseCoin`이 D98 풀(설계용·판정용) 암호자산과 겹치면 거절한다.
- **모든 시세 요청은 `symbol=`을 명시한다.** symbol을 생략한 요청과 WS 구독은 쓰지 않는다. 도구는 요청 URL을 만들 때 allowlist 밖 심볼이면 예외로 멈춘다(테스트로 고정).
- 목록과 그 sha256, 보류·거절 목록을 시세 요청 전에 수집 기록에 남긴다.

## 2. 관측 범위와 판정 후보 구간 (PR #59 P2-2, PR #60 P2-1·P2-2)

경계 시각 **B = 2026-09-01T00:00:00Z**(배타적 끝)를 결과를 보기 전에 고정한다.

| 구간 | 용도 |
|---|---|
| 과거 자료: 각 심볼 상장 시각 이상, **B 미만** | 0단계 관측(설계 참고용) |
| **[B, T0)**: T0는 첫 실시간 요청 시각 | **아무것도 받지 않는다.** D104 판정 후보 구간 |
| [T0, T0 + 14일) 실시간 호가 표본 | 0단계 관측(설계 참고용). 판정에 쓰지 않는다 |

- **과거 요청 경계**
  - 모든 과거 요청(1시간봉, 5분봉, index·mark 가격봉, 펀딩)은 시작·종료 인수를 **항상 둘 다** 넣는다. 종료는 모든 요청·재시도·페이지에서 `B − 1ms` 이하로 둔다. 시간 인수를 생략하면 최신 자료부터 돌려주므로 생략하지 않는다.
  - 봉은 구간 전체가 B 이하인 것만 쓴다(1시간봉 시작 ≤ B − 1h, 5분봉 시작 ≤ B − 5m). 펀딩은 정산 시각 < B인 것만 쓴다.
  - **상장 시각 ≥ B인 심볼(305개 중 81개)에는 과거 요청(봉·펀딩·가격봉)을 하나도 보내지 않는다.** 이 심볼은 실시간 호가 표본으로만 관측한다.
  - API가 B 이상의 자료를 돌려주면 저장하지 않는다. 그 요청 이후 수집을 멈추고, 수집 기록에 **관측 사고**로 남긴다(심볼, 요청, 받은 시각 범위). 사고가 나면 그 심볼의 해당 범위는 D104 판정 후보에서 뺀다.
- **실시간 요청은 `orderbook`만 쓴다.** `tickers`는 `prevPrice24h`·`price24hPcnt`·24시간 고저·거래량 같은 [T − 24h, T] 과거 필드를 함께 돌려주므로 쓰지 않는다. 그러면 판정 후보 구간의 끝부분을 보게 되기 때문이다. `orderbook` 응답은 호가·수량·시각·갱신 번호뿐이다. 실제 응답 필드를 수집 기록에 남기고, 예상 밖 과거 필드가 있으면 멈춘다.
- T0는 수집 시작 때 기록한다. 남겨 둔 [B, T0)는 과거 약 6개월 중 2개월 남짓이다. 표본이 작고 현재 Trading 종목만으로 만든 목록이라 생존 편향이 있다는 점은 D104에서 명시한다.

## 3. 받을 것

| 데이터 | 엔드포인트(공개, `category=linear`, `symbol=` 명시) | 범위 | 필드 |
|---|---|---|---|
| 1시간봉 | `/v5/market/kline`, `interval=60`, `start`·`end` | 상장 ~ B | start, open, high, low, close, volume, turnover |
| 경계 5분봉 | `/v5/market/kline`, `interval=5`, `start`·`end` | 요청은 상장 ~ B의 5분봉 페이지(1,000개 단위), **저장은 4절 세션 시작 경계 R마다 `[R − 5m, R + 15m)`인 봉만**, 그리고 `R + 15m ≤ B` | 같음 |
| index·mark 가격 1시간봉 | `/v5/market/index-price-kline`, `/v5/market/mark-price-kline`, `interval=60` | 상장 ~ B | start, open, high, low, close |
| 펀딩 이력 | `/v5/market/funding/history`, `startTime`·`endTime` | 상장 ~ B | 정산 시각, 율 |
| 최우선 호가 | `/v5/market/orderbook`, `limit=1` | [T0, T0 + 14일), **5분마다** 심볼별 | 응답 시각, bid1·ask1 가격·수량 |
| 호가 깊이 | `/v5/market/orderbook`, `limit=50` | [T0, T0 + 14일), **1시간마다** | 응답 시각, 양쪽 50단계 가격·수량 |

- 5분봉은 경계마다 따로 요청하면 약 10만 회가 들어서, B 이전 관측 구간 안에서 페이지로 받고 경계 창만 저장한다(PR M2-10a 구현 결정). 받는 범위가 넓어지지만 모두 B 이전 관측 구간이라 판정 후보 경계는 그대로다.
- 세션 표는 `tools/d103_sessions.py`가 `exchange_calendars`(선택 패키지, 프로젝트 의존성 아님)로 한 번 만든 `docs/reports/D103-sessions.json`이다. 버전을 표에 기록하고, 수집·통계 코드는 이 표만 읽는다.
- 요청 속도는 초당 5회 이하로 둔다. 오류나 빈 응답은 재시도 3회 뒤 결측으로 기록한다. 결측을 0이나 직전 값으로 채우지 않는다.
- 저장은 새 SQLite `data/backtest/market_data/d103-tradfi-structure.sqlite`에만 한다. **D98 DB는 열지 않는다.** 수집이 끝나면 data_hash를 계산해 기록한다.
- 분할 등으로 거래가 중단된 구간은 결측으로 둔다. 과거 kline이 분할 비율로 조정된다는 점(1차 2절)을 기록하고, 공지된 중단 구간은 갭 통계에서 뺀다.
- WS, 키가 필요한 API, 주문 API는 쓰지 않는다.

## 4. 세션 라벨과 경계

- 각 시각에 그 심볼의 기초 시장 세션을 붙인다: 정규장, 프리·애프터, 야간, 휴장(주말·공휴일), 조기 종료, 불명.
- 달력: US는 NYSE(서머타임 포함, 프리 04:00·정규 09:30·애프터 16:00~20:00 ET), KR은 KRX(09:00~15:30 KST), HK는 HKEX(점심 휴장 포함), CN은 해당 거래소다. 원자재·외환은 기준 시장의 세션(CME 등, 주말 휴장)을 쓴다.
- Bybit의 세션 구분은 Bybit 재량이므로(1차 2절) 거래소 공식 세션을 기준으로 쓰고, 그 차이를 한계로 적는다.
- **세션 시작 경계 R**: 휴장·야간 뒤 프리장 시작, 정규장 시작, 주말·공휴일 뒤 첫 세션 시작. 경계 종류별로 나눠 보고한다.
- 달력 출처와 버전을 기록한다. 달력이 없는 날은 "불명"으로 두고 통계에서 뺀다.

## 5. 볼 통계 (수익률 아님)

| 통계 | 정의 |
|---|---|
| 거래대금 | 1시간봉 24개가 모두 있는 날만 일 거래대금으로 센다. 30일 평균은 완결된 날 30개가 연속으로 있는 시각에서만 계산한다. 그 밖은 "계산 불가"로 세고 0으로 바꾸지 않는다. 결과는 D99 등급(5M·20M·50M·200M) 구간별 심볼 수다. 거래 0 시간봉 비율은 있는 봉 중에서만 센다 |
| 스프레드 | 같은 응답 안에서 `(ask1 − bid1) / mid`, `mid = (ask1 + bid1) / 2`. 세션별 중앙값·90분위. 빈 호가·한쪽 호가는 따로 비율로 센다 |
| 깊이 비용 | 같은 응답 안에서 고정 명목 **1,000 / 5,000 / 20,000 USDT**를 호가에 대어 본다. 매수 `(VWAP_매수 − mid) / mid`, 매도 `(mid − VWAP_매도) / mid`로 둘 다 0 이상인 비용이다. 세션별로 보고, 깊이가 모자라면 "미체결"로 센다. 다른 시각의 가격과 연결하지 않는다 |
| 재개 전후 변화(근사) | 경계 R마다 `abs(P_after / P_before − 1)`. `P_before`는 5분봉 `[R − 5m, R)`의 종가, `P_after`는 5분봉 `[R + 10m, R + 15m)`의 종가다. 둘 중 하나라도 없으면 빼고 개수를 센다. 경계 종류·시장별 중앙값·95분위·최대를 보고한다. **실제 손절 체결 갭이 아니라 무기한 가격의 15분 근사치**다 |
| index·mark 동일 값 | 휴장 시간대의 index·mark 가격 1시간봉 중 `open = high = low = close`인 봉이 연속된 길이(시간). 결측 봉은 연속을 끊는다. 시간봉 해상도의 관측일 뿐, 그 안의 연속 정지를 증명하지 않는다 |
| 펀딩 | 율의 절대값 중앙값·95분위. 상한 도달은 과거 상한 이력이 없으므로 **"현재 메타데이터 상한 대비 비율"**로만 보고한다 |

- RPI 등 API에 보이지 않는 호가는 반영되지 않는다는 한계를 적는다.

## 6. 보고서가 답할 질문

1. D99 등급(20M 이상)을 만족하는 심볼이 몇 개이고, 그중 한국·미국 대형주와 원자재·외환은 무엇인가.
2. 휴장·주말 스프레드와 깊이 비용이 정규장 대비 몇 배인가. 우리 규모(명목 1천~2만 USDT)에서 D99 슬리피지 가정이 맞는가.
3. 세션 재개 전후 15분 변화(근사)의 분포는 어떤가. 이 단계에서는 손절 거리와 비교하지 않는다. 비교 기준은 D104에서 사전 고정한다.
4. 휴장 중 index·mark가 같은 값으로 머문 시간은 어느 정도인가(1차의 "갱신 둔화 정도 미확인"을 관측으로).
5. 이 결과로 1차 제안("보류에 가까운 조건부 진행")을 유지·상향·하향할지.
