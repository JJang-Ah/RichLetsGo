## 범위

### 만들 것 (`src/richletsgo/strategy/`)

1. **지표** (`strategy/indicators.py`) — 마감된 봉 목록을 받아 마지막 봉 기준 값을 돌려준다. 값이 부족하면(워밍업) `None`.
   - 단순 이동평균 SMA(n)
   - 채널 최고가·최저가 (최근 n개 봉의 high 최대·low 최소). **현재 봉을 포함할지**를 인자로 명시한다. 돌파 판단은 "직전 n개 봉의 채널"과 "현재 마감 봉의 종가"를 비교한다.
   - 볼린저 밴드(n, k): 중심선 SMA(n), 위·아래 = 중심선 ± k × 표준편차(모표준편차, n개)
   - RSI(n): Wilder 방식 평활
   - ATR(n): Wilder 방식, True Range 사용
   - 각 지표의 공식과 워밍업 길이를 docstring에 적고, 손으로 계산한 작은 예시를 테스트 기대값으로 쓴다.

2. **S1 추세 상태** (D66) — 일봉, 계약별
   - S1-A 이동평균 교차: SMA(fast) > SMA(slow) → `LONG`, < → `SHORT`, 같으면 직전 상태 유지. 워밍업 중 `FLAT`.
   - S1-B 채널 돌파: 종가 > 직전 N일 최고가 → `LONG`, 종가 < 직전 N일 최저가 → `SHORT`, 그 밖에는 직전 상태 유지. 워밍업 중 `FLAT`.
   - 출력: 추세 상태와 함께, 상태가 `LONG`/`SHORT`이면 그날의 S1 **시장 신호**(`MarketSignal`, signal_id = (S1, 계약, 봉 시작, kind))를 낸다(01 2.2절: 추세가 유지되는 동안 매일). 진입 여부는 에피소드 규칙(D59)이 정한다.

3. **S1 손절** (D68)
   - 초기 손절: 롱이면 직전 M일 최저가, 숏이면 직전 M일 최고가.
   - 추적: 일봉 판단마다 새 채널 값이 유리한 쪽(롱은 위, 숏은 아래)으로 움직였을 때만 손절을 옮긴다. 불리한 방향으로는 옮기지 않는다.
   - PR #22 P2: 손절 후보가 종가와 같거나 이미 넘어섰으면(롱 ≥ 종가, 숏 ≤ 종가) ENTRY 대신 EXIT를 낸다. 추세는 유지하고 상태 손절가는 직전 값을 유지한다. 직전 목표가 없는 최초 판단은 None을 유지하며 EXIT 가격 필드에만 후보를 담는다. 실행기는 EXIT를 청산 라우터로만 전달하고 trail_stop을 호출하지 않는다.
   - 출력은 "원하는 손절가"다. tick 정렬과 크기 계산은 M1-03, 실제 수정 주문은 M1-04가 한다.

4. **S2 신호** (D66, D67) — 1시간봉, 계약별, S1 추세 상태를 입력으로 받는다
   - S1이 `FLAT`이면 신호 없음. S1 방향과 같은 방향으로만 진입 신호(D14).
   - 아래에서 `t`는 현재 마감 봉, `t-1`은 직전 봉이다. 밴드·RSI는 **각 봉 시점에서 그 봉까지의 데이터로 계산한 값**이다(직전 봉 비교에 현재 밴드를 쓰지 않는다).
   - S2-A 볼린저 진입: 롱 `close[t-1] < lower[t-1]` **그리고** `close[t] >= lower[t]`. 숏 `close[t-1] > upper[t-1]` **그리고** `close[t] <= upper[t]`. 청산: 롱 `close[t] >= mid[t]`, 숏 `close[t] <= mid[t]`.
   - S2-B RSI 진입: 롱 `rsi[t-1] < low` **그리고** `rsi[t] >= low`. 숏 `rsi[t-1] > high` **그리고** `rsi[t] <= high`. 청산: 롱 `rsi[t] >= neutral`, 숏 `rsi[t] <= neutral` (`low`, `high`, `neutral`은 매개변수).
   - 최대 보유 봉 수를 넘으면 청산 신호.
   - S1 추세가 바뀌면 S2 청산 신호(01 1.2절).

5. **S2 손절** (D68): 진입 예상가 ∓ K × ATR(1시간봉, n). 추적 없음.

6. **매개변수**
   - 각 전략의 매개변수를 불변 dataclass로 정의한다(예: `S1AParams(fast, slow, exit_channel)`). 값 범위를 생성 시 검사한다(예: fast < slow). **기본값을 두지 않는다**(M2-04가 격자에서 고른다).

7. **신호 타입** (M1-04 병합 후 확정)
   - M1-04의 `MarketSignal(strategy, symbol, bar_start, kind, direction, entry_price, stop_price, limit_price)`를 쓴다. 타입을 따로 만들지 않는다.
   - `kind`는 `ENTRY` 또는 `EXIT`. `MarketSignal`은 `EXIT`에도 가격 두 개를 요구하므로 규칙을 정한다: `EXIT`의 `entry_price`는 그 봉 종가, `stop_price`는 S1이면 현재 원하는 손절가, S2면 진입 때 손절가. 위험 게이트는 퇴장 신호로 크기를 계산하지 않는다(M1-04 `is_exit`).
   - S1의 추세 전환은 반대 방향 `ENTRY` 신호로 나타난다. 라우터가 기존 에피소드의 청산 의도를 만든다(M1-04).

8. **입력·상태 계약** (M3-04 경계 저장과 맞춤)
   - S1: 계약의 마감 일봉 목록 + **직전 S1 상태**(추세, 현재 원하는 손절가)를 받아 새 상태와 신호를 돌려준다. 추적 손절은 직전 손절가보다 유리할 때만 바뀐다.
   - S2: 계약의 마감 1시간봉 목록 + **그 시점의 S1 상태** + **열린 S2 에피소드 정보**(없으면 `None`: 방향, 진입 봉 시작, 진입 때 손절가)를 받는다. 청산 신호(중심선·중립·최대 보유·추세 전환)는 열린 에피소드가 있을 때만 낸다. 진입 신호는 에피소드가 없을 때만 낸다.
   - 상태와 출력은 불변 dataclass이고 JSON으로 왕복할 수 있어야 한다(M3-04 ④단계가 저장·복원). 같은 입력이면 같은 출력(결정적).

9. **추적 손절 연결은 별도 작업 [M2-02a](M2-02a-trailing-stop.md)**
   - 이 작업은 "원하는 손절가"만 계산한다(3번). 거래소 손절까지 반영하는 경로(목표 갱신, 주문별 맞추기, 전송 직전 확인, 늦은 진입 체결 처리)는 M2-02a가 **먼저** 만든다(PR #20 Codex 검토).

## 구현 입력과 계산 규약 (2026-10-23)

- 진입점은 `strategy.candidates.s1_a/s1_b/s2_a/s2_b`. `ClosedBars(symbol, interval, bars=tuple(...), as_of=UTC시각)`가 마감 여부를 검증한다. 계약·주기 혼합, 중복·역순·누락 봉은 거절한다. 누락 데이터는 M2-01/M2-03에서 해결하고 임의로 봉을 채우지 않는다.
- 과거 시점을 계산하려면 **계산 전에** `history.through(봉 시작)`으로 접두 구간을 선택한다. 뒤에 추가된 봉은 지표·손절·신호에 들어오지 않는다. S1 직전 상태는 평가 일봉보다 이전이어야 하며, S2에 전달하는 S1 일봉은 평가 시간봉 마감까지 마감된 것이어야 한다. 같은 시각에 마감되는 일봉/시간봉은 M2-03에서 일봉 판단을 먼저 처리한다.
- SMA/밴드/ATR 워밍업은 n개, 현재 봉을 제외하는 채널은 n+1개, RSI는 n+1개다. S1 손절 채널까지 준비되지 않으면 FLAT·신호 없음이다. ATR 첫 TR은 high-low이며 최초 n개 TR 평균으로 시작한다. RSI 최초 n개 변화량 평균으로 시작하고, 상승·하락 모두 0이면 50이다. Wilder RSI·ATR은 각 함수 안에서 마지막 L=10×n개 봉으로 자른 뒤 그 창에서 seed와 평활을 계산한다. L개 미만은 주어진 봉을 쓰되 기존 워밍업 길이는 그대로다. 전체 이력 Wilder와는 다른 고정 창 정의이며 백테스트·운영에 똑같이 적용한다.
- 계산 전 구간에서 Decimal만 쓰며 정밀도 34자리의 지역 컨텍스트를 쓴다. float 변환이 없으므로 가격 경계에서도 이진 부동소수점 오차를 도입하지 않는다. 틱 정렬·크기 계산은 기존 계층에 맡긴다.
- S1 방향 전환은 새 방향 채널로 초기화하며 같은 방향에서는 원하는 손절가를 유리하게만 움직인다. 매일 ENTRY 시장 신호를 출력하고 실제 유지/진입/청산은 라우터가 판단한다.
- S2 보유 봉 수는 `(현재 봉 마감 - 진입 봉 시작) / 1시간`이다. 진입 봉부터 세고, 정확히 최대 봉 수일 때는 유지하며 초과 시 EXIT다. 진입 봉은 신호 봉이 아니라 실제 진입이 속한 봉을 실행기가 전달한다.
- S1 FLAT은 **신규 진입 없음**을 뜻한다. 열린 S2는 FLAT을 포함한 추세 변경·최대 보유 초과 시 지표 워밍업과 무관하게 청산한다(01 1.2절). EXIT는 해당 봉 종가와 에피소드의 초기 손절가를 그대로 넣는다.
- ATR=0 또는 계산된 초기 손절가가 0 이하이면 신규 진입 신호를 내지 않는다. `S1State`, `S2Episode`, `S1Result`, `S2Result`의 `to_dict/from_dict`는 Decimal을 문자열, 시각을 UTC ISO 문자열로 JSON 왕복한다.
- 실행기는 진입 신호로 미리 S2Episode를 만들지 않고 실제 열린 에피소드 정보만 전달해야 한다. 이 모듈에는 거래소 호출·DB 저장·수량 계산이 없다.

검증: `tests/test_strategy.py` 51개(손계산, 미래 정보 차단 4후보, 롱·숏 대칭, 밴드 시점 fixture, 보유 경계·추세 소멸 청산, JSON 왕복, M2-02a 연결 포함). 실제 체결·성과 비교는 M2-03에서 다룬다.

### PR #22 성능·청산 보완

- `required_bars(params)`가 현재/직전 지표와 손절에 필요한 평가 창 길이를 반환한다. S2-B 직전 RSI 때문에 RSI 창+1개를 요구한다. M3-04는 최소 이 수의 마감 봉을 적재한다.
- M2-03은 전체 데이터를 한 번 검증한 뒤 `history.through(start, lookback=required_bars(params))`로 평가 구간만 전달한다. 접두 전체를 매번 복사·검증하지 않으며 before_last도 필요한 개수만 잘라 쓴다.
- 같은 마지막 L개가 있으면 이력 앞에 데이터를 추가해도 RSI·ATR 값은 정확히 같다. 고정 창 도입은 수렴 근사가 아니라 전략의 명시적인 계산 규약이다.
